## Referral use

Append a referral code to any share URL:

`https://werise-mu.vercel.app/share/promo-01.html?ref=WR8K3P7`

When a person clicks the Facebook image, the share page sends them to We-Rise with the referral code intact, and the existing referral engine handles first-valid-referral attribution.

## Facebook cache

After changing an image or its metadata, run that exact share URL through Meta Sharing Debugger and use **Scrape Again**.

## Internal share library

`https://werise-mu.vercel.app/share/` shows all nine images and provides Copy Link buttons. It is marked noindex and is not linked from the normal We-Rise navigation.
