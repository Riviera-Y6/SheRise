# We-Rise Facebook Clickable Image Share System

The share library now contains 11 promo images.

## Cleanest Facebook posting flow
1. Open https://werise-mu.vercel.app/share/
2. Copy a promo link.
3. Paste it into a Facebook post.
4. Wait until the large image preview appears.
5. Delete the typed URL from the post text.
6. Add your normal marketing copy and publish.

The Open Graph title and description on the promo pages are intentionally visually blank, so the image dominates the card. Facebook may still render its own small domain/site label under a link preview; that part is controlled by Facebook and cannot be reliably removed from an organic link post.

## Referral links
Append `?ref=REFERRALCODE`, for example:

`https://werise-mu.vercel.app/share/promo-03.html?ref=WR8K3P7`

The visitor is redirected into We-Rise with the referral code preserved.

## Easy Facebook sharing workflow

Open `https://werise-mu.vercel.app/share/`, choose a creative, and press **Share on Facebook**. The button opens Facebook's share composer using that creative's share URL, so the URL does not have to be pasted into the post text field. Type/paste the normal daily marketing copy above the attached link preview and publish.

The optional referral-code box in the share library appends `?ref=CODE` before opening Facebook, preserving We-Rise referral attribution. Leave it blank for normal We-Rise marketing.

Facebook controls its own link-card chrome and may still display a small domain/site label under the image. Organic link posts cannot reliably suppress that platform-controlled label.
