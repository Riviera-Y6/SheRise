# We-Rise Fuel-It / Brandstofverligting Tab

This build adds a dedicated Fuel-It / Brandstofverligting member tab immediately after RentIt / HuurDit in the bottom navigation.

The tab includes the current monthly calculation model:
- R166 monthly membership
- R10 BackMi allocation
- R33 Fuel-It / Brandstofverligting calculation basis
- R123 remains in the We-Rise model

Calculator formula:
Qualifying active paying referrals × R33 = monthly Fuel-It calculation basis.

The Home Fuel-It information block now opens this new tab directly.

No new database migration or environment variable is required for this UI/calculator addition.
